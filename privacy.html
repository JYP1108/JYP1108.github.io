개인정보처리방침

시행일 2026년 11월 27일

생활 계산소(이하 "사이트")가 어떤 정보를 처리하고 어떤 정보를 처리하지 않는지 밝힙니다. 이 방침은 성격이 전혀 다른 두 영역을 나누어 설명합니다. 하나는 이용자가 계산기에 입력한 값, 다른 하나는 광고를 게재하는 과정에서 구글과 광고 파트너가 처리하는 정보입니다.

계산기 입력값

급여·공제액·근무 조건 같은 입력값은 이용자의 브라우저 안에서만 계산에 쓰입니다. 서버로 전송되지 않고, 사이트나 제3자의 저장 공간에 남지도 않습니다.

광고 제공

광고는 구글 애드센스로 게재됩니다. 구글과 제3자 광고 파트너가 쿠키, 웹 비콘, IP 주소, 기기·브라우저 정보를 수집·이용해 광고를 표시하고 성과를 측정할 수 있습니다. 맞춤 광고는 구글 광고 설정에서 끌 수 있습니다.

1. 계산기 입력값은 서버로 전송되지 않습니다

사이트의 계산기는 모두 이용자의 브라우저에서 실행됩니다. 실수령액, 연말정산 환급액, 실업급여, 주휴수당, 대출 이자를 계산할 때 입력하는 급여, 공제액, 근무 기간, 나이, 대출 조건 같은 값은 화면에서 계산에 쓰일 뿐이며, 사이트 서버로 전송되지 않습니다.

입력값을 보관하는 저장 공간도 두지 않습니다. 브라우저 저장소(localStorage, sessionStorage)나 쿠키에 입력값을 기록하지 않고, 주소창(URL)에 값을 담아 두지도 않습니다. 계산은 페이지를 새로 고치거나 닫으면 처음 상태로 돌아가고, 그때 입력값은 함께 사라집니다. 사이트 운영자와 광고 사업자를 포함해 누구도 이용자가 무엇을 입력했는지 볼 수 없습니다.

계산 결과를 캡처해 문의 게시판에 올리는 경우에만 해당 내용이 공개될 수 있습니다. 이때 올릴 내용은 이용자가 직접 고르는 것이며, 실제 급여 대신 예시 숫자를 넣는 방법은 문의 페이지에 적어 두었습니다.

2. 사이트가 직접 수집하는 정보

사이트에는 회원가입, 로그인, 댓글, 검색 기록 저장 기능이 없습니다. 이름, 전화번호, 이메일, 주소, 주민등록번호, 결제 정보를 입력받는 칸도 없습니다. 따라서 사이트가 직접 모으는 개인정보는 없으며, 이를 판매하거나 마케팅에 쓰지 않습니다.

문의는 GitHub 저장소의 이슈 게시판에서 받습니다. 이 게시판은 누구나 볼 수 있는 공개 공간이므로, 작성자가 남긴 계정 이름과 글 내용은 공개됩니다. 무엇을 적을지는 작성자가 정하고, 개인정보가 포함되지 않게 하는 것도 작성자의 몫입니다.

3. 서버 접속 기록

사이트는 GitHub Pages에서 호스팅됩니다. 페이지를 열 때 접속한 IP 주소, 브라우저 종류와 버전, 운영체제, 접속 시각, 요청한 페이지 주소 같은 기술적 정보가 호스팅 사업자인 GitHub에 의해 서버 기록으로 남을 수 있습니다. 이 기록은 사이트 제공과 보안, 장애 대응을 위한 것이며, 사이트 운영자가 이 기록으로 개별 이용자를 식별하거나 따로 보관하지 않습니다. GitHub의 처리 방식은 GitHub 개인정보 보호 성명을 따릅니다.

4. 광고 제공: 구글 애드센스와 광고 파트너

사이트는 구글 애드센스(게시자 ID pub-1098242508288731)를 통해 광고를 게재합니다. 계산기 입력값과는 별개로, 광고를 내보내는 과정에서 구글과 제3자 광고 파트너가 아래와 같은 정보를 수집하고 이용할 수 있습니다.

사용하는 기술

광고 게재와 측정에는 쿠키, 웹 비콘(픽셀), IP 주소, 기기 식별자, 브라우저·기기 정보가 쓰일 수 있습니다. 쿠키는 이용자가 방문한 사이트가 브라우저에 남기는 작은 텍스트 파일입니다. 웹 비콘은 광고가 노출되거나 클릭되었는지 확인하기 위해 페이지에 심는 작은 이미지나 스크립트입니다. IP 주소는 접속한 지역을 대략적으로 파악하고 부정 노출을 걸러내는 데 쓰입니다.

수집·이용될 수 있는 정보

쿠키와 기기 식별자, 브라우저 종류와 언어·화면 크기, 운영체제, 대략적인 접속 지역(IP 기준), 방문한 페이지와 시각, 광고 노출·클릭 기록이 수집될 수 있습니다. 구글과 제3자 광고 사업자는 이 정보를 광고 표시, 같은 광고가 반복되지 않게 하는 빈도 제한, 광고 성과 측정, 부정 클릭 방지, 관심사에 맞춘 광고(맞춤 광고) 제공에 이용합니다. 이 과정에서 제3자 광고 사업자가 자사의 쿠키를 저장하거나 읽을 수 있습니다.

구글은 이 사이트나 다른 사이트를 방문한 기록을 바탕으로 광고를 표시하기 위해 광고 쿠키를 사용합니다. 구글이 파트너 사이트의 정보를 어떻게 사용하는지는 Google이 파트너 사이트나 앱의 정보를 사용하는 방식에 정리되어 있습니다. 광고에 쓰이는 쿠키의 종류와 목적은 Google의 쿠키 사용 안내에서 확인할 수 있습니다.

맞춤 광고를 끄는 방법

맞춤 광고를 원하지 않으면 구글 광고 설정에서 맞춤 광고를 끌 수 있습니다. 구글 계정이 없어도 이 페이지에서 '맞춤 광고 사용 안함'을 선택할 수 있으며, 이 경우에도 광고는 계속 표시되지만 관심사와 무관한 내용으로 나옵니다.

구글이 아닌 제3자 광고 사업자의 맞춤 광고는 Digital Advertising Alliance의 소비자 선택 페이지(aboutads.info)에서 한 번에 해제할 수 있습니다. 모바일 기기에서는 설정 메뉴에서 광고 식별자를 재설정하거나 맞춤 광고를 제한할 수 있습니다.

5. 쿠키 관리

브라우저 설정에서 쿠키 저장을 거부하거나 이미 저장된 쿠키를 삭제할 수 있습니다. 쿠키를 막으면 광고가 관심사와 무관하게 표시될 수 있지만, 계산 기능은 쿠키와 관계없이 정상적으로 동작합니다. 쿠키를 관리하는 방법은 쓰는 브라우저의 도움말(Chrome, Safari, Edge, Firefox 등)에서 확인할 수 있습니다.

6. 제3자 제공 및 국외 처리

사이트는 이용자의 개인정보를 제3자에게 판매하지 않습니다. 사이트가 직접 수집하는 개인정보가 없기 때문입니다. 다만 아래 두 사업자가 각자의 목적과 책임 아래 정보를 처리합니다.

  • Google LLC(미국) — 애드센스를 통한 광고 게재·측정, 위 4항의 정보 처리. Google 개인정보처리방침 적용.
  • GitHub, Inc.(미국) — GitHub Pages 호스팅과 접속 기록 보관. GitHub 개인정보 보호 성명 적용.

두 사업자 모두 미국에 본사를 두고 있어, 위 정보가 국외 서버에서 처리될 수 있습니다. 이용자는 브라우저의 쿠키 차단과 4항의 맞춤 광고 해제로 이 처리의 범위를 줄일 수 있습니다.

7. 이용자의 권리

사이트가 보관하는 개인정보가 없으므로 사이트에 열람·정정·삭제를 요청할 대상은 없습니다. 광고 과정에서 만들어진 쿠키와 식별자는 이용자가 직접 삭제하거나 차단할 수 있고, 맞춤 광고 설정은 구글 광고 설정에서 언제든 바꿀 수 있습니다. 문의 게시판에 남긴 글은 작성자가 직접 수정하거나 삭제할 수 있습니다.

8. 아동의 개인정보

사이트는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 일부 계산기는 나이를 입력받지만, 이 값은 브라우저 안에서 계산에만 쓰이고 전송되거나 저장되지 않습니다.

9. 외부 링크

가이드와 이 페이지에는 국세청, 고용노동부, 국가법령정보센터, 구글, GitHub 같은 외부 사이트로 가는 링크가 있습니다. 링크를 눌러 이동한 사이트의 개인정보 처리 방식은 그 사이트의 방침을 따르며, 사이트는 이에 대해 책임지지 않습니다.

10. 방침의 변경

법령이나 서비스 내용, 광고 방식이 바뀌면 이 방침을 수정할 수 있습니다. 중요한 변경이 있을 때는 바뀐 내용과 시행일을 이 페이지에 함께 반영합니다. 이전 시행일은 2026년 11월 24일이고, 2026년 11월 27일 개정에서 계산기 입력값 처리와 광고·쿠키 처리를 별도 항으로 나누고 광고 파트너의 정보 처리 범위와 맞춤 광고 해제 방법을 보강했습니다.
