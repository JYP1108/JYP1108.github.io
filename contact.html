문의

계산 결과가 이상하거나, 다뤘으면 하는 계산기가 있다면 알려 주세요. 요청이 많은 주제부터 만듭니다.

이런 내용을 받습니다

  • 계산 결과가 법령이나 공식 안내와 다른 경우 (근거 자료를 함께 보내 주시면 빠릅니다)
  • 화면이 깨지거나 계산이 되지 않는 경우 (사용한 기기와 브라우저를 적어 주세요)
  • 추가로 필요한 계산기나 가이드 주제
  • 가이드 내용 중 사실과 다른 부분에 대한 지적

보내는 곳

사이트는 GitHub Pages로 운영되며, 문의는 저장소의 이슈로 받습니다. 아래 링크에서 새 이슈를 만들면 확인할 수 있습니다.

GitHub 저장소에 의견 남기기

이슈 작성이 어렵다면 계산기 페이지의 결과를 캡처해 함께 보내 주세요. 어떤 입력값에서 문제가 생겼는지 확인하는 데 도움이 됩니다.

스크린샷을 올리기 전에 꼭 확인해 주세요. 실제 급여·세금 정보 대신 예시 숫자를 입력해 재현해 주세요. 스크린샷을 올릴 때는 개인정보나 민감한 숫자를 반드시 가려 주세요. GitHub 이슈는 누구나 볼 수 있는 공개 게시판입니다.

답변 기준

개별 세무 상담이나 법률 자문은 하지 않습니다. 사이트는 계산 도구와 해설을 제공하는 곳이고, 개인의 구체적인 사정에 맞는 판단은 국세청(126), 고용노동부(1350), 금융기관 같은 공식 창구에서 받으셔야 합니다.

계산 오류 신고는 근거 법령과 함께 확인한 뒤 수정하고, 수정 내역은 해당 페이지의 기준일과 함께 표시합니다.

자주 받는 질문

제가 입력한 금액이 저장되나요?

저장되지 않습니다. 모든 계산은 브라우저 안에서 이뤄지고, 입력값은 서버로 전송되지 않습니다. 자세한 내용은 개인정보처리방침에 있습니다.

계산 결과를 그대로 신고에 써도 되나요?

참고용으로만 쓰시고, 신고나 청구에는 공식 기관의 확인을 거치세요. 회사의 급여 구성이나 개인별 공제 요건에 따라 실제 금액이 달라집니다.
